# Chrome Quick Translate

Простое расширение для Chrome, которое переводит выделенный текст через DeepL API Free прямо на странице.

## Возможности

- Перевод выделенного текста на веб-страницах
- Маленькая кнопка перевода рядом с местом, где отпущен курсор
- Всплывающее окно с переводом прямо на странице
- Ширина окна перевода примерно подстраивается под ширину выделенного текста
- Окно перевода можно перетаскивать за иконку в правом верхнем углу
- Иконка перетаскивания видна только при наведении на окно
- Настраиваемые темы: светлые, тёмные и цветные
- Настройка размера шрифта перевода
- Выбор шрифта перевода: системный sans-serif, Times New Roman или Georgia
- Язык перевода по умолчанию: русский
- Выбор целевого языка перевода
- Сохранение DeepL API ключа в хранилище расширения Chrome
- Иконка расширения в стиле кнопки перевода с символом `中`

## Установка

1. Склонируйте репозиторий или скачайте его ZIP-архивом.
2. Откройте Chrome и перейдите по адресу:

```text
chrome://extensions
```

3. Включите режим разработчика.
4. Нажмите Load unpacked.
5. Выберите папку проекта.
6. После обновлений кода нажимайте Reload у расширения на странице `chrome://extensions`.

## DeepL API ключ

Расширение использует DeepL API Free.

1. Создайте аккаунт DeepL API Free:

```text
https://www.deepl.com/pro-api
```

2. Откройте popup расширения.
3. Вставьте DeepL API ключ.
4. Нажмите Save settings.
5. Нажмите Test key, чтобы проверить ключ.

Бесплатные DeepL API ключи обычно заканчиваются на `:fx`.

## Настройки внешнего вида

Откройте popup расширения по закреплённой иконке в панели Chrome.

Доступные настройки:

- Theme — тема окна перевода и кнопки перевода
- Font — шрифт текста перевода
- Font size — размер текста перевода с кнопками `-` и `+`
- Target language — язык, на который нужно переводить выделенный текст

Настройки сохраняются в `chrome.storage.sync` и применяются к новым окнам перевода на страницах.

## Использование

1. Выделите текст на странице.
2. Рядом с местом, где вы отпустили курсор, появится маленькая синяя кнопка.
3. Нажмите на кнопку.
4. Перевод появится во всплывающем окне.
5. Чтобы закрыть окно, кликните вне его.
6. Чтобы переместить окно, наведите курсор на окно и перетащите его за маленькую иконку в правом верхнем углу.

Ширина окна перевода рассчитывается по ширине выделенного фрагмента, но ограничивается шириной экрана.

## Важное замечание по безопасности

В текущей MVP-версии DeepL API ключ хранится прямо в хранилище Chrome расширения. Это подходит для личного использования, но не рекомендуется для публичного расширения.

Для публичного распространения лучше использовать backend-proxy, например Cloudflare Worker, и хранить DeepL API ключ на сервере.
